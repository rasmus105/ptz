# About

Vibe-coded command line executable to render pdfs in the terminal.

**Currently only support kitty graphics protocol.**

## Usage

```bash
ptz [options] <file>

ptz my-document.pdf
```

## Features

- Vim-like motions (`j/k` + `Ctrl+u/d` for scrolling, `h/l` for next/prev page,
  `:` for command line,...)
